# Laporan Keuangan 💰

Aplikasi pelaporan keuangan pribadi dengan fitur lengkap dan visualisasi 3D.

## Fitur

- 🔐 **Autentikasi** — Login dengan username dan password
- 📊 **Dashboard** — Ringkasan keuangan dengan visualisasi 3D interaktif
- 📅 **Date Picker** — Pilih periode tanggal untuk filter transaksi
- 💰 **Kelola Transaksi** — Tambah, edit, dan hapus transaksi pemasukan/pengeluaran
- 📋 **Laporan** — Daftar transaksi lengkap dengan pencarian, sorting, dan filtering
- 📈 **Statistik** — Total pemasukan, pengeluaran, saldo bersih, dan breakdown kategori
- 🎨 **UI Modern** — Glass morphism, animasi Framer Motion, gradient dinamis

## Tech Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4
- **3D:** Three.js, React Three Fiber, React Three Drei
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Utilities:** date-fns, clsx, tailwind-merge
